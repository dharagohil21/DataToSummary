Creating LLM for summary data from Cofluence page

How to run the program:

1. Installing dependencies:
pip3 install -r requirements.txt

2. set the details and run the program:
python3 main.py


How to execute this feature:

1. upload the resume on confluence page(update the confluence page data in the file)
2. run the program using the above commands
3. it will show the result in command line prompt
